# Нячанг сейчас

Одностраничный сайт с погодой, состоянием моря и курсом донга для тех, кто едет в Нячанг.
Собирается скриптом без зависимостей и обновляется сам через GitHub Actions каждые три часа.

## Как это устроено

- `scripts/build.mjs` тянет данные, сохраняет их в `data/latest.json` и пишет готовую страницу в `dist/`.
- `src/page.mjs` и `src/styles.css` — разметка и оформление. Все цифры попадают в HTML при сборке.
- `config.json` — партнёрские ссылки. Пока список пуст, блок на странице не показывается.
- `.github/workflows/update.yml` — сборка по расписанию и публикация на GitHub Pages.

Если источник недоступен, берутся прошлые данные из `data/latest.json`. Если прогнозу погоды больше суток, сборка останавливается и на сайте остаётся прошлая версия.

## Источники данных

| Что | Откуда |
|---|---|
| Погода | MET Norway Locationforecast 2.0 (CC BY 4.0) |
| Волны | NOAA WAVEWATCH III через PacIOOS ERDDAP |
| Температура воды | NASA JPL MUR SST через NOAA CoastWatch |
| Курсы валют | Банк России |

## Локальный запуск

```bash
node scripts/build.mjs
```

Нужен Node.js 22 или новее.
